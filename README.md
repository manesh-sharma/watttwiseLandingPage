# WattWise Landing Page

Static public landing page for WattWise.

## Demo link
The page currently links to:
`https://watttwise-ai.streamlit.app/`

If your deployed Streamlit URL is different, replace that URL in `index.html`.

## Run
Open `index.html` directly or use VS Code Live Server.

## Deploy
This is pure HTML/CSS, so it can be deployed on Vercel, GitHub Pages, Netlify, etc.

For Vercel: import the GitHub repository, choose **Other** as the framework, leave build/output commands empty, and deploy.
